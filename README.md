# GreLka's Den v2

Обновлённая версия сайта GreLka без странной луны и зубчатого леса.

## Что изменилось

- Новый задний фон: мягкое северное сияние, звёзды, синие огни, тёплый свет логова.
- Убраны непонятные фигуры снизу и объект справа сверху.
- Добавлены быстрые переключатели настроения: игры / кино / чат / ночь.
- Добавлен раздел “Интерактив логова”.
- Добавлены команды чата с копированием.
- Добавлен “Волчий сигнал”.
- Добавлена “Фраза вечера”.
- Сохранены пасхалки: 5 кликов по портрету и ввод WOLF.

## Как использовать

Открой `index.html` в браузере.

## Версия v3: расширенная галерея

Добавлены новые изображения GreLka в `assets/gallery/`.
Галерея теперь поддерживает:

- фильтры по настроению кадра;
- крупный выбранный кадр;
- 3D-наклон карточек при наведении;
- световой блик на карточках;
- открытие в лайтбоксе;
- переключение стрелками клавиатуры ← / →;
- закрытие через Esc.

Основные файлы для правки:

- `index.html` — структура галереи;
- `styles.css` — внешний вид и анимации;
- `script.js` — фильтры, лайтбокс и интерактив.


## Версия v4

- Галерея вынесена в отдельный файл `gallery.html`.
- На главной странице остался аккуратный блок-переход в галерею.
- В галерее добавлен большой просмотрщик с плавными анимациями переключения.
- Изображения в альбоме больше не обрезаются: карточки подстраиваются под реальные пропорции.
- Работают стрелки клавиатуры, свайп на телефоне, миниатюры и фильтры по настроению.


## V5 clean gallery

- `gallery.html` полностью переделана.
- Убран длинный лишний текст сверху.
- Убран белый системный ползунок миниатюр.
- Большой просмотрщик показывает изображения через `object-fit: contain`, без жёсткой обрезки.
- Галерея теперь использует аккуратную сетку карточек и плавные переходы между кадрами.


## V6 gallery polish

- Нажатие на большое фото открывает его крупно.
- Нажатие на карточку в альбоме также открывает фото крупно.
- Внизу галереи добавлены красивые кнопки `На главную` и `Наверх`.
